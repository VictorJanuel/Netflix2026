# Netflix2026

## Présentation

Netflix2026 est un projet web développé en PHP et CSS autour de l'univers de Netflix.

Le projet est organisé en plusieurs dossiers permettant de séparer la configuration, les styles et le code PHP.

## Technologies utilisées

- PHP
- CSS
- Git et GitHub

## Structure du projet

```text
Netflix2026/
├── config/     # Fichiers de configuration
├── css/        # Feuilles de style
├── php/        # Scripts PHP
└── README.md   # Documentation du projet
```

## Installation

### Prérequis

- PHP installé sur la machine.
- Git pour récupérer le projet.
- Un navigateur web.

### Étapes

**1. Cloner le dépôt**

```bash
git clone https://github.com/VictorJanuel/Netflix2026.git
```

**2. Accéder au dossier**

```bash
cd Netflix2026
```

**3. Lancer le serveur PHP**

```bash
php -S localhost:8000
```

**4. Accéder au site**

Ouvrir l'adresse suivante dans un navigateur :

http://localhost:8000

Selon la structure du projet, des étapes de configuration supplémentaires peuvent être nécessaires.

## Configuration

Les fichiers de configuration sont regroupés dans le dossier `config/`.

Vérifiez les paramètres nécessaires au fonctionnement de l'application avant de la lancer.

Ne publiez pas d'identifiants, de mots de passe ou de clés secrètes dans le dépôt.
